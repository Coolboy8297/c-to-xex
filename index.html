C → XEX (Xbox 360)

Push .c files → GitHub Actions builds Xbox 360 homebrew for you.

How it works

  1. Fork the repo
  2. Drop your .c files into source/
  3. Push
  4. Download the artifact from the Actions tab

Full instructions and source are in the repository (replace with your actual repo URL after you push).

What you get

  • *.elf32 — ready for XeLL
  • *.xex — when available
